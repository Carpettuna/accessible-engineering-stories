# Accessible Engineering Stories

Create a professional portfolio website for a mechanical engineer specializing in assistive technology, wheelchair adaptations, accessibility solutions and customized mechanical devices for people with disabilities.

Overall objective:
Create a sophisticated engineering portfolio that showcases real projects completed during university internship experience. The website should appeal to mechanical engineering employers, assistive technology companies, rehabilitation engineering organizations and product development teams.

Design direction:

Modern, minimalist industrial design aesthetic.

Professional color palette: deep navy blue, muted teal, white and light grey.

Clean typography and generous spacing.

High-quality image galleries.

Responsive design for desktop, tablet and mobile.

Subtle animations without excessive visual effects.

Website structure:

Home

Professional introduction.

Headline: "Engineering for a More Accessible World."

Brief introduction to my engineering specialization.

Featured project photographs.

Clear navigation to projects and contact information.

Projects

Individual project case studies.

Image galleries.

Problem definition, user requirements, engineering approach, design process, fabrication and final outcome.

Space for CAD drawings, technical illustrations and photographs.

About Me

Professional biography.

University education and internship experience.

Engineering interests and professional goals.

Skills & Tools

CAD software.

Mechanical design.

Prototyping and fabrication.

Material selection and product development.

Contact

Professional email address.

LinkedIn profile.

Contact form if technically feasible.

Technical requirements:

Generate clean, maintainable source code.

Use a static website architecture wherever possible.

Make it compatible with GitHub Pages hosting.

Avoid unnecessary databases, paid APIs and backend dependencies.

Keep all photographs and website assets exportable.

Include SEO metadata and accessibility features.

Make project content easy to update and expand.

Start by creating the homepage and overall design system. Use realistic placeholder photographs until I upload my actual engineering project photographs.
